# Form state and shadcn fields

The nonvisual `@rc-component/form` engine owns nested values, validation, preservation and submit callbacks. `AppForm` and `AppField` only compose those contracts with the official shadcn Field primitives. There is no Ant Design visual dependency or `antd` import alias.

- Import `AppForm`, `AppField`, `FormList`, `useForm`, `useWatch`, `useFormInstance` from `./ui-patterns/form`.
- Replace `<Form>` with `<AppForm>`; remove `layout`, `colon` and visual Ant Design props. Use Tailwind `className` for layout. `disabled` is inherited by field controls. Existing `form`, `initialValues`, `onValuesChange`, `onFinish`, `preserve` and rc validation props retain their meaning.
- Replace `<Form.Item>` with `<AppField>`. Change `extra` to `description`. `label`, `rules`, `name`, `dependencies`, `shouldUpdate`, `preserve`, `hidden`, `noStyle`, `valuePropName`, `trigger` and `validateTrigger` remain supported. A `shouldUpdate` function child receives the form instance, as before.
- Replace `Form.List` with `FormList`; it is the rc engine's direct export.
- Replace `Form.useForm`, `Form.useWatch` and `Form.useFormInstance` with named hooks. `useFormInstance` reads the engine's public FieldContext. `useForm` and `useWatch` are unchanged direct exports.
- A shadcn `Input` uses native `onChange`/`value` and needs no mapping. A shadcn Select uses `trigger="onValueChange"`; a shadcn Checkbox or Switch uses `trigger="onCheckedChange" valuePropName="checked"`. Do not wrap controls to imitate Ant Design event contracts.
- Required and invalid states, description/error IDs and label association are generated by AppField. Explicit control IDs are preserved.
- Fields must have one control child (or a form render function). Compound custom controls should forward their accessible ID and input metadata.

`ByteQuantityInput` keeps unaccepted numeric text local until valid and preserves byte precision. `PolicyDateInput` uses official Calendar/Popover controls and explicit confirmation, preserving the stored RFC3339 string until an intentional edit.

`NumericInput` uses `value` / `onValueChange` and keeps partial numeric text local. Its `onInputText` callback runs **after** an accepted number has reached the form, so policy draft-settlement logic can compare raw text with the current form value. `resetKey` remounts only the inner input. `min`, `max`, and integer `precision={0}` enforce native validity; also attach domain rules to AppField when invoking `form.validateFields()` programmatically. AppField defaults validation to the control's declared trigger, unless explicitly overridden.
