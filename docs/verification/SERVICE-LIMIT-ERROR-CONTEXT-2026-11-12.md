## Narrow allowance

At the existing exact `accordion-down` completion, only the current owned aria-invalid control gets the submitted-context reveal after the ordinary ring reveal. A private optional parameter identifies that exact completed-open accordion. Each associated label/help/error rectangle must already lie entirely inside its actual client clip before it can contribute. Other overflow-hidden/clip ancestors, clip/clipPath, hidden/sr-only/closed content and privacy guards remain unchanged. Oversized combined context retains the control/ring fallback. Ordinary AppForm callers have no new allowance; valid correction/remount remains ring-only.

There is no delayed work, stored stale target, focus call, primitive overflow change or broader automatic scrolling.
