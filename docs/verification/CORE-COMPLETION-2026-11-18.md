## Remaining unsupported work

The request for complete support is **not fully closed** by this increment:

1. No managed-sing-box execution layer matching managed-Xray admission, durable metering, selective revocation and lease guarantees. Ordinary core statistics are not equivalent to enforcement. Managed-Xray remains its declared VLESS/TCP profile; enabling Vision/REALITY/UDP requires measured runtime integration rather than deleting guards.
2. WireGuard, Tailscale, Naive, ShadowTLS and HTTP proxy connection models remain absent. These need explicit credentials, endpoint lifecycle, routing and target-specific semantics, not opaque native passthrough. Generic arbitrary connection fields are not accepted as a shortcut.
3. Complete native-program migration (DNS, groups, rules, services and every upstream setting) is not implemented. Source import remains connection extraction. Native extensions retain ownership and generated-identity protections.
4. VLESS newer encryption options, unrestricted multiplex/socket configuration, arbitrary QUIC detours and all advanced HY2/TUIC settings remain outside this tested subset.
5. Real sing-box native traffic/TUN acceptance remains constrained by the documented local netlink startup denial. New parser/API results are not a substitute. No bypass, external deployment or unverified global capability claim was introduced.
