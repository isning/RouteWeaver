# 浅色侧栏键盘焦点

本轮基线：`90990d0d5808175f0f854637dacafb1c302e81ee`。

## 发现与设计边界

项目使用 React SPA、Tailwind 4、shadcn/ui 语义变量及浅色/深色主题。
保持原有组件和层级，只调整浅色侧栏焦点变量，不替换组件或添加依赖。

本轮重新下载、校验并查看了 `2458fbe` 的真实浏览器焦点采样：
[运行 42865667554](https://github.com/isning/RouteWeaver/actions/runs/42865667554)，
附件 `13787287079`，SHA256 为
`7408d1dfbcf2021db868ca86ae68017436c7ec3f8420cb1e5171c516f8a96ea6`。
该采样是共享控件的独立合成页面，不等于真实工作区全页面验收。

在桌面浅色侧栏按钮的左侧直边，焦点环像素为 `(161,161,161)`，相邻
背景为 `(250,250,250)`，对比度为 **2.475:1**。未聚焦时同一点是背景色，
没有另一个可见边框或轮廓承担焦点提示。当前浅色侧栏仍使用该采样记录的
`oklch(0.708 0 0)` 变量。复放这些像素时，新增的 3:1 判据失败。

参考：用户选择的 Refactoring UI skill 中
[`15-beyond-the-book.md` 的 Focus states](https://github.com/edisonmbli/refactoring-ui-skill/blob/main/skills/refactoring-ui/references/15-beyond-the-book.md)。
焦点规则是该参考的外部补充，不是原书结论。本轮不宣称整个应用通过 WCAG。

## 修改

- 浅色 `--sidebar-ring` 改用项目已有中性色阶 `oklch(0.556 0 0)`。
- 保留原来的 2px 焦点环、按钮尺寸、布局、交互和深色变量。
- 浏览器采样器在浅/深两种主题下直接读取截图的直边与邻接背景像素，
  要求至少 3:1；同时检查焦点状态确实改变、控件宽高保持不变。
- 原生 Tab 可能滚动页面，因此不把屏幕坐标不变当作焦点合同。

## 验证范围

已完成：保存采样的图片查看、SHA256 校验、基线像素失败复放、应用及采样器
构建、应用和浏览器文件类型检查、57 项相关导航与焦点 DOM 回归、浏览器用例发现、
静态检查及源码秘密扫描。独立复核没有发现阻塞问题；按建议保留直接用于测量的
PNG，并明确使用视口截图和 CSS 像素缩放，避免测量与附件不对应。

新样式的实际像素尚待对应提交的 CI 产出。本地浏览器仍受宿主 `socket()`
启动限制，本轮没有放宽沙箱，也没有把源码颜色计算当成修正后截图验收。
移动侧栏、完整深色覆盖和危险操作焦点属于后续独立采样。没有部署或真实数据操作。
