# 有限核心诊断（2026-11-14）

这是固定故障类别的上报链路，不是完整日志浏览器。部署事件没有被替换或冒充核心日志。没有任意文件读取、shell、远程开启、原文下载或导出接口。

## 开启与边界

节点管理员可在已注册、允许本地核心执行的 `supervise` / `catalog` 模式显式增加 `--core-diagnostics`；默认关闭。只处理该 Agent 启动/验证的核心进程输出，不读取系统日志或其他进程。控制面只接受当前实例 enrollment，读取接口仅管理员可访问。

版本限定为实际合成实验覆盖的 Xray 26.3.27、26.10.31 和 sing-box 1.14.3、1.14.4。其他版本（包括 managed-xray）不套用邻近版本识别规则。

固定类别：
- Xray：监听地址被占用、证书文件不存在、协议配置不受支持。
- sing-box：证书文件不存在、协议配置不受支持、网络初始化权限不足。

识别器只生成枚举和版本/时间；路径、目标地址、标签、凭据与原始内容均不进入队列、磁盘批次、上传或管理员接口。未知内容丢弃并计数，不提供“安全原文”回退。

## 限量与交付

单行最大 4096 字节；每个输出流每秒最多处理 64 KiB。内存队列最多 128 个事件；每次最多 32 个，每 10 秒尝试上传。控制面每实例接受间隔至少 5 秒（精确重试例外）；请求最大 16 KiB；本地批次文件最大 32 KiB 且要求私有目录/普通私有文件。

待发送批次先落盘再发送，失败后按相同序号及摘要重试。服务端精确重复幂等，同序号不同内容/跳号拒绝。只有收到匹配回执后才推进本地序号。尚未刷入批次的内存事件可能随异常退出丢失；离线已落盘批次保留到确认，不能承诺不丢失或实时完整日志。

控制面最多 256 个实例历史、每实例最近 128 个事件，按**接收时间**保留 24 小时。启动及每分钟清理，同时读取时清理；当前 enrollment 的小型序号边界保留，已失效历史删除以释放容量。离线备份是独立保留副本，不自动追溯清除。omitted/dropped 为最近批次计数且最多 1000000，不是累计总数。

`recent` 只代表最近收到报告（包含空报告），不是运行正常、成功捕获输出或链路健康证明。

## 实验和验证

使用仓库校验过的官方固定版本二进制、合成配置与凭据；无真实 VPS 操作。四个版本分别执行缺失证书/未知协议；Xray 两版本实际占用本机监听端口复现 bind 失败。sing-box 运行启动在当前容器被 netlink 权限拒绝，未将此解释为监听成功，也不宣称已验证其端口冲突识别。

Xray 26.10.31 的 tcp 错误大小写不同于 26.3.27，规则按版本分别匹配。额外实验发现 Xray warning 级别仍可输出含地址的 accepted 访问记录，这也是不上传原文的理由。没有观测到足够的真实运行中连接失败样本，未扩展到通用连接故障分类。

自动测试覆盖真实公开接口上的登记隔离、撤销、管理员权限、精确重试、冲突、速率、容量/历史截断、保留、重启待发恢复、原文不外泄、输入限量和不支持版本；进程验证路径用合成核心 shim 复现固定错误，不能替代真实 VPS 运行验收。

独立只读安全审查未发现阻断性原文泄露/鉴权问题；审查提出退出等待与报告时效语义，已采用有界等待和非阻塞关闭，并向 UI 明确上述时效含义。完整集成、浏览器与远端 CI 由协调者另行记录，本文不代称通过。
