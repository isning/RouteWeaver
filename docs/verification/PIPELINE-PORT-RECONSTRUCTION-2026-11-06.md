# Collection pipeline port intent reconstruction

Reconstructs reported v100/v112 intent, not unavailable historical bytes. Raw override-port text belongs to a collection opening, keyed by source identity plus step identity, with aggregate processing in a distinct namespace. It survives reorder, disabling, collapsed source processing and temporary source-subtask sheet unmounts. Invalid text changes dirty/revision state, clears stale previews, and blocks both save and preview before transport. The invalid source stage expands and focuses its field, repeatedly. Removing a step/source prunes its draft; a new collection opening resets drafts. Accepted numeric model changes occur only after exact decimal integer validation. Blank input still clears an optional override; untouched zero values remain unchanged. No generic NumericInput edits.

Public page/transport DOM regression source covers collapsed source recovery, source/aggregate same-step-ID isolation, fractional tails, partial text, exponent correction, disabled aggregate steps, arrow repair, blank/untouched zero and deletion. Additional public regression source covers both ports through source-subtask unmount/return and cancel-discard/confirmed-discard followed by a new editing session reusing the same IDs. Reorder remains a source-reviewed ownership path; two-source ordering permutations should be expanded before acceptance. None of these tests has executed.

Only Git/Python/text source operations were performed. git diff --check is a whitespace check, not a TypeScript check. All test, typecheck, build, browser, backend and whole-product verification remain UNRUN. No Node/npm/Go/gofmt/browser/server/install/network/push/deploy operations. No historical passing report is current evidence. Requires the group commit's frontend draft-integer control. The component is a bounded input adapter, not a replacement for backend domain validation.

Source-subtask readback: opening a source task hides the collection TaskSheet without replacing the CollectionsPage owner or calling changeDraft. Returning clears the source task while retaining portDrafts and stageDisclosures. Cancelling discard retains them; confirmed discard calls changeDraft(null), pruning port drafts and clearing disclosures. edit then resets raw drafts and recovery focus for the next collection session. The added DOM specifications require the original source input to become disconnected before returning, distinguishing an actual remount from an immediate hide/show.
