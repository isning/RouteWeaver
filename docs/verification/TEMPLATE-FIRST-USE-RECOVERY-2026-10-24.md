# 模板首次使用：读取恢复与清晰状态

日期：2026-10-24。范围：`TemplatesPage → 查看并使用 → 版本/草稿/插槽选择 → 应用到草稿`。本记录是有界验收，不是全站质量、Google 水平或完整 WCAG 符合性声明。

## 用户问题与最终变化

首次使用模板时，版本、客户端配置或节点集合读取失败可能被当作空列表；来源、平台连接读取失败没有局部恢复动作。完成条件只检查非空 ID，版本失效还可能回落到模板卡片版本。

最终界面区分读取中、暂停、失败和已确认缺失。失败只在相关位置显示短状态，例如“暂时无法加载来源”，旁边提供“重新加载来源”，不使用暗示用户提交失败的通用红色“操作未完成”标题。读取恢复保留选中的版本、目标、引用方式、绑定和已知名称；确认缺失的选择仍显示为不可用，不静默换成第一个对象。

依赖按任务划分：

- 节点处理预设只依赖版本与节点集合列表。
- 客户端模板依赖版本与客户端配置列表；规则资源只来自所选配置的 `ir.resources`。
- 只有连接插槽读取相关来源、节点集合和平台连接候选。未读全候选不等于已知本地连接失效：来源或平台读取失败时，可独立确认的本地 IR 连接仍可应用。
- 远程候选仅由就绪读取结果提供；重新读取/失败时，旧远程绑定不冒充当前可用。明确切换目标或版本仍沿用原有清空绑定语义。
- 重新加载仅执行读取，不自动 POST，不重放应用。应用仍需用户点击，发布订阅仍需独立确认。

没有修改 API、会话所有权、存储、全局 ErrorNotice、模板更新实际差异模型或发布流程；没有引入新框架、独立 UX 模式、`useEffectiveProfileInputs` 或 collection-preview POST。

## 最终覆盖与保留限制

13 个新公共页面用例覆盖来源503恢复、版本/目标/引用方式保持、无自动写入；预设/无槽/本地连接不受无关失败阻断；绑定删除与目标删除不静默替换；目标/节点集合/版本读取失败恢复；实际 collectionId 路径保持绑定；延迟和暂停；已选版本移除不回落。

浏览器断言恢复前零写入、点击后仅一个精确模板 select POST，v1/目标/固定版本/本地绑定保持，来源恢复后远程候选可选，重试按钮可获得焦点并以 Enter 激活，文档/对话框无横向溢出。它使用实际构建 JS/CSS＋受控 HTTP，不证明真实后端断网、持久化成功或真实发布行为；没有修改或增加后端写入权限。

现有会话测试是公共 App 的通用所有权/过期/迟到响应/离线不回放合同，不称为新增模板专属登录场景。未改变原有 10 秒 DOM、45 秒浏览器预算；一 worker、零 harness retries。当前协调者完整门禁是 root Go nonrace＋webplain，未启用 native/process-runtime；历史限制保留。本轮不把先前全门禁的独立 deadline 失败改写为成功。

## 设计依据与适配范围

- 沿用指南目录 **GS-01 / WCAG 2.2**。[Understanding SC 4.1.3 Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)由协调者于2026-10-24复核：重要等待、错误和结果状态应可由程序识别，无需夺走焦点。Understanding 是解释材料，非独立认证。本轮在失败状态使用单一局部 status 区域，避免嵌套竞争播报；不据此宣称全页符合性。
- [GOV.UK Design System — Error message](https://design-system.service.gov.uk/components/error-message/)由协调者同日复核：服务问题与用户输入错误应区分，输入应保留。原文针对 GOV.UK 表单；这里是读取恢复的情境适配，不声称其规定当前中文或组件。source503 不呈现为用户需纠正字段的校验失败。
- 项目 `CONTENT-DESIGN-RULES.md`：只呈现当前决定需要的对象、动作、状态、后果与恢复；局部真实错误不隐藏，技术验收限制不写成产品常驻提示。
