# 来源任务延续与操作上下文细化

2026-10-27，WIP46。沿用 WIP45 的完整编辑器和 React／Ant Design 组件，处理来源详情缺少继续任务入口、对象名称不一致、比较边界不清，以及窄屏操作身份和焦点丢失的问题。后续有限检查补充了同类表格与对话框的实测问题；十个已审查分项已组合为 r4；该轮完整类型检查发现测试定位选项不兼容，全前端另有两项来源等待测试失败；三处测试文件的修正已独立接受，生产代码不变，r5 已冻结，完整前端 1,722 项及适用检查通过。首轮与 r4 失败及历次定位修正保留，精确组合的 16 阶段浏览器复验已独立接受，新的目标式复走也已完成：受支持任务没有新增证据充分的本地修正，平台深入检查仍受夹具限制。结果与证据范围见[验证记录](../verification/UX-REFINEMENT-2026-10-27.md)。

## 任务入口与真实状态

| 问题 | 本轮决定 | 保留的边界 |
| --- | --- | --- |
| G01 来源详情只有查看和关闭，无法直接继续配置 | 对明确启用且已有接受快照的独立来源，提供“用此来源新建分流配置”，进入既有完整编辑器，带入该来源并标记为未保存草稿 | 不改变默认分流动作，不自动接受候选、保存或发布。嵌入其他草稿的来源子任务不提供此出口 |
| G02 原“连接素材”进入“连接端点”，原“链路配置预览”进入可编辑“线路”，后者与平台线路混称 | 统一“连接端点”和“链路配置”；新建、字段、引用、删除与记录同步使用对应对象名 | 仅澄清既有链路配置入口，不改平台线路名称、内部身份、路由或接口；“配置”不暗示已部署 |
| G03 已有配置检查更新显示文本相同，但来源候选仍待确认，比较范围不明显 | 当已加载的分流配置引用来源或集合时，在原有文本比较结果旁说明已接受来源的范围 | 不推断待确认候选是否存在，不新增读取、接受动作或发布限制；配置包等其他内容不由文本相同推定 |
| G04 首页暂停标记与周期详情缺少就地下一步提示 | 仅在权威状态为 `paused` 时显示“如需恢复平台服务，请联系管理员检查服务授权。” | 不猜测暂停原因，不提供未经授权的恢复按钮或保证恢复；其他状态及个人订阅的状态不被改写 |

G01 的进入请求只属于发起时的账号会话，且只消费一次。地址中仅携带不透明标记，不放来源名称、地址或凭据。关闭、后退及离开继续受未保存修改确认保护；放弃后，前进或普通导航不重建草稿。较新的导入失败或候选待确认，不抹掉仍有效的旧接受快照；进入后来源暂停或消失，保留引用并提供既有恢复路径，不静默换来源或去向。

G03 保留原句“生成的配置文本与已发布版本相同。”，仅在适用上下文紧接一句：

> 比较使用已接受的来源内容；如有待确认更新，请先在订阅来源中确认，再重新检查。

这句话不重复到次级分类摘要，也不出现在内容已变化、比较未知、本地输入或配置上下文缺失的场景。“配置文本相同”始终不等于“全部交付内容相同”。

## 操作上下文与布局

| 已观察问题 | 收敛方式 | 不做的扩展 |
| --- | --- | --- |
| VIS-01 来源、用户和规则资源表格横向滚到操作区后，目标名称已在视口外 | 仅在表格实际溢出时，在行操作旁显示可换行的完整目标名称；保留原列和宽度 | 宽屏不无条件重复身份，不删列或缩短身份来消除滚动 |
| 行操作中的弹层取得焦点时，底层表格可能被错误滚动 | 焦点显露逻辑只处理操作容器内的真实 DOM 后代；排除通过 portal 渲染的弹层 | 不干预弹层自己的焦点，也不以全局焦点捕获替代局部归属 |
| VIS-02 模板卡片标题换行后，同类动作位置不齐 | 仅调整模板库卡片的伸展与底部动作布局，保持完整标题和自然高度 | 不固定卡片高度，不截断名称，不重写全局卡片样式 |
| VIS-03 用户和服务工具栏有无任务职责的“集中管理，按需展开” | 删除这一处共用填充文字，保留搜索和任务控件 | 不换成另一句口号，不为可选说明槽补字 |

后续有限横表清单区分已有验证、固定身份列、只读无动作与尚未验证的页面，不把整张清单算成通过。服务与公告的右侧编辑区，以及另外七个已观察的端点、链路、用户组和基础设施／线路列表，复用同一按实际溢出显示完整目标的方式；字段、列宽、原动作和身份不变。注册清单与草稿配置不代表运行健康或已部署。

动作显露还需区分键盘与指针：部分可见按钮在鼠标按下后若因聚焦而滚动，松开时可能已不是同一按钮。修正只让具有 `focus-visible` 的目标触发上下文显露，保留真实 DOM 后代与 portal 排除条件，不在指针按下／松开之间挪动动作。

VIS-04 明确保留空列表中的搜索和创建控件。页头创建入口在加载、错误、有数据时保持同一位置；空态的同名动作提供就地下一步，两者打开同一表单，不代表不同结果。保留工具栏也避免刷新或删除后条件卸载造成焦点变化，并让已有搜索词保持可见。已观察的窄屏空态没有裁切或拥挤，尚无证据表明跨页重写空态能改善任务完成，因此此项以保留关闭，不是延期修复。

## 草稿与焦点的归属

**规则资源表单按实际值判断修改。** 新建资源、编辑资源和公开引用沿用既有表单，归一化可选字段后比较真实值；未改动或改回原值可直接关闭。文件输入保留实际 `File`，失败重试不丢字段或更换载荷。存在修改时，取消、Escape 和导航先确认；继续编辑回到当前任务，明确放弃才清除。

**等待中的提交仍是一个任务。** 请求期间保留决定区、稳定的动作名称与焦点边界，阻止重复写入和不适用的退出。失败保留输入并可重试；成功后恢复相应入口。取消不能声称撤销已发出的请求，旧回调不能关闭后来打开的表单或写入旧错误。嵌套放弃确认及其关闭阶段也保留所属任务的离开保护。

**焦点在对话框里，不等于焦点可见。** 资源表单提交后的忙碌按钮和失败后的重试动作，需要在动画稳定后、没有追加 Tab 或滚动的情况下可见。修正沿用就近显露，仅在当前提交拥有焦点、相关展开动画属于当前表单时处理；不通过计时器、轮询或较晚强抢焦点补救。模板应用／发布和公告编辑的已审查分项同样保留草稿、忙碌状态、单次提交与任务归属。模板三个选择控件补充与已有可见标签一致的精确可访问名称，避免选中值或装饰符污染名称，而非宣称此前完全没有标签。

**普通 Tab 边界、等待状态和失败恢复分别检查。** 有限清单检查了直接对话框，并把确认调用与浏览器原生确认分开记录。已观察的正向 Tab 离开文档不能被 Escape 可关闭、反向能返回或重复出现同一输入节点掩盖。用户编辑与空邀请表单的普通边界、来源／用户名称修改被截留后释放 503、来源嵌套放弃和其他九个表面的普通边界／关闭返回，分别保留独立候选证据；不把局部取消成功扩大为保存或发布成功。共享边界逻辑的默认行为不变，只有明确需要的表面选择原生滚动或末端下载链接边界；聚焦链接不触发下载。选择器和来源关闭等待当前任务的动画收尾后再完成父层关闭与入口返回；已离开或后来打开的任务不接收旧回调。未具备安全运行前提的操作性对话框保持未验证，不为补齐清单制造凭据、授权或健康数据。

**窄屏导航按用户决定安排焦点。** Escape 或选择当前页面返回菜单入口；接受切换到其他页面后，焦点进入持久的主内容区域。拒绝放弃保留草稿、地址和当前导航选择。快速开关、关闭动画、视口切换及账号变化不会让旧关闭回调夺走新任务的焦点；后来打开的对话框或已取得焦点的控件优先。关闭后保留的导航不进入可访问树或键盘顺序。

## 方法与验证边界

本轮沿用[内容设计规则](CONTENT-DESIGN-RULES.md)、[既有界面审查](REFACTORING-UI-AUDIT-2026-10-20.md)与[UX 方法](UX-METHODOLOGY.md)：先检查任务和对象关系，再检查真实状态、动作位置及呈现。没有新增外部设计来源；[来源分层](UX-GUIDELINE-SOURCES.md)及适用边界不变，这些项目判断不是 Google 认证。

复测从公开任务入口与可观察结果出发，主要回归位置为：

- 来源进入与比较范围：`web/src/source-profile-continuation.dom.test.tsx`、`web/src/source-comparison-scope.dom.test.tsx`。
- 对象命名与暂停指引：`web/src/admin-task-lifecycle.dom.test.tsx`、`web/src/subscription-overview-status.dom.test.tsx`。
- 资源草稿及焦点：`web/src/resource-modal-lifecycle.dom.test.tsx`、`web/src/resource-modal-focus.dom.test.tsx`。
- 来源／选择器关闭与有限对话框边界：`web/src/source-editor-close.dom.test.tsx`、`web/src/chooser-close-lifecycle.dom.test.tsx`、`web/src/matrix-modal-boundary.dom.test.tsx`、`web/src/output-access-boundary.dom.test.tsx`。
- 导航焦点：`web/src/navigation-focus.dom.test.tsx`。
- 表格目标身份、弹层边界和模板布局：`web/tests/action-context-and-template-layout.ui.spec.ts`。

受控 API 下的浏览器呈现、DOM 行为、源码复核和真实后端接受是不同证据。组合脚本和独立目标复走各自保留结果，不合并为全产品验收；具体计数、失败记录和版本归属见验证记录。实际浏览器缩放快捷键尝试未生效，窄 CSS 视口只能证明相应视口的重排，不能证明真实缩放通过。目标任务复走不是人类可用性研究；本轮不推定完整辅助技术或 WCAG 符合性。

本轮不新增后端能力、接口、依赖或基础／专业双轨界面，不改变来源接受、授权、默认去向和订阅发布合同，也不进行真实服务部署、外部客户端应用或流量验证。没有画面溢出、局部测试通过或文字变少，都不能单独证明任务已可理解或产品已全面验收。

最终目标复走保留了两处轻微绕路：资源名称打开替换表单，以及平台状态调查经过个人订阅与管理页面。前者没有承诺只读详情，后者的可见状态与授权检查建议没有误导；尚未建模的深入检查也不能证明生产流程错误。它们没有显示自动破坏、输入丢失或被阻断的受支持任务，本轮不据此新增入口或文案。这个停止点限于已有证据与本轮范围，不是“零摩擦”或一切改进已经穷尽。
