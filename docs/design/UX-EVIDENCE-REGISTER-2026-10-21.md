## 新增源码发现：UX-I09 焦点环 token 对比度（2026-10-21）

- **证据来源**：[`web/src/styles.css`](../../web/src/styles.css) 的源码值及本轮修正记录；按相对亮度公式计算，非渲染测量。关联 UX-11、UX-12 / GS-01；内部优先级 P1。
- **位置/观察**：`web/src/styles.css` 全局焦点环原色 `#85b7a0`。按 WCAG 相对亮度公式与白色、页面 `#f6f7f9`、浅色 `#e9f3ee` 背景分别计算为 **2.26:1 / 2.11:1 / 2.00:1**。
- **处理**：改为已有品牌色 `#167565`；对上述背景分别为 **5.58:1 / 5.20:1 / 4.92:1**；补充 `select` / `textarea` 的 `:focus-visible` 选择器。已应用到预览源码，尚待浏览器复测。
- **实现状态**：已修改，等待实际界面复测。**证据范围仅为源码 token 算术与修正记录**；上述三个配色计算改善不等于真实渲染的相邻色、焦点覆盖或完整 WCAG 通过。浏览器状态仍是 **UNVERIFIED**。
- **复测要求**：在对应构建中用键盘遍历按钮、链接、输入框、选择框、文本域和组合控件，记录实际计算样式、相邻背景、焦点可见性/遮挡及截图；核对样式优先级、组件覆盖、深色区域、禁用与弹层状态。记录构建和实际证据后再关闭问题，不以此颜色覆盖推断全应用无障碍符合性。
