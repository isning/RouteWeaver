## 这份记录覆盖什么

本轮盘点了 17 个真实主页面、2 个旧地址兼容入口，以及 107 个弹窗、侧栏与确认框的代码调用点。其中 58 个为 Dialog/Sheet，49 个为确认调用；同一个任务可能有加载、就绪等多个调用点，**107 不等于 107 个独立任务**，也不意味着每种数据、错误或操作组合均已实际打开。

`profiles` 和 `outputs` 都回到“我的订阅”，不是另外两个产品页面。另有一个目前未被路由使用的基础分流组件，已做源码检查，不计作已走通的页面。

证据分开记录：

- **实际界面**：在浏览器中看到并操作过的指定状态，包括桌面与明确标注的窄 CSS 视口。
- **合成界面场景**：使用演示数据或隔离组件呈现生产 UI，仅验证该界面的布局和交互；不是后端执行或真实业务成功。
- **源码/单元检查**：检查实现和行为断言；不能替代实际像素、动画、设备或辅助技术验收。
- **待复查/受阻**：尚未完成、当前数据无法到达，或需要单独授权的步骤。不会用相似组件的结果替代。

### 三种视口的最新转发界面复查

在 390×568、1024×568、1180×757 的实际 CSS 视口中，紧凑目标摘要的内容宽度与可视宽度分别为 60、95、179 px，长文本自然换行，没有再绘制到相邻目标数量列。应用复核区的两个复选框均为 16×16 px；返回按钮窄屏为 50×44 px，短屏和桌面为 50×36 px，后果说明、确认项及操作区均可见，正文仍可滚动。仅打开合成检查结果后返回，没有执行应用。

### 集合阶段页签与历史详情复查

集合加工预览在桌面、390×568 和 1024×568 均保持单行页签；页签条可视高度 32 px，四个页签实际高度均为 25 px，完整选中阶段名称与结果数量分开显示。窄屏原生 Right、End、Home 可切换阶段，End 将末项滚动到可视范围内（334 px 可视宽度、453 px 内容宽度、119 px 横向滚动位置）。没有保存集合或执行真实加工。

桌面还实际打开了有数据的历史生成详情和技术文件。界面区分历史保存记录、当次校验与服务器应用；该检查不构成重新校验，也不补足尚未查看的历史详情窄屏及其他状态组合。
