## 共享组合

ContextLayout 以自身可用宽度而非视口判断；58rem 可用宽度才分配 14rem 辅助栏、2rem 间隔，主区仍有至少 42rem。索引在窄屏先于主区，辅助用量在主区之后。仅足够高的宽屏允许目录 sticky，短视口正常滚动。

SectionIndex 使用 type=button，不改 hash/history，不经过工作区离开流程。实际目标获焦，滚动无需动画；当前区域根据可见目标与滚动位置更新。索引不拥有表单、查询或草稿状态。

- 基本设置、备份、账号安全复用同一目录。目标 ID 使用实例稳定的 useId，双挂载备份测试验证第二个目录不会跳到第一个任务。
