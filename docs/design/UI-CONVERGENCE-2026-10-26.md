# 管理任务连续性与界面状态收敛

2026-10-26，WIP45。沿用 WIP44 的完整编辑器和现有 React／Ant Design 组件，集中处理已复现的任务丢失、旧请求干扰新任务，以及状态和必要信息不易辨认的问题。本轮已完成有界本地行为与画面接受，范围和保留限制见[验证记录](../verification/UI-CONVERGENCE-2026-10-26.md)。用户设计验收仍待完成。

## 本轮决定

| 已确认问题 | 收敛方式 | 需要保留的行为 |
| --- | --- | --- |
| 管理表单修改后，取消、Escape 或页面导航可能直接丢弃草稿 | 使用既有未保存修改与放弃确认机制，按真实字段变化判断草稿 | 继续编辑保留内容；只有明确放弃才清除。失败后保留输入和可读错误 |
| 较早的管理保存或模板操作完成后，可能关闭后来打开的任务 | 将请求结果绑定到发起时的任务身份；写入等待期间保护当前决定区 | 旧任务可以刷新对应数据，但不能关闭新任务或把旧错误写到新表单；取消不谎称撤销已发出的请求 |
| 基本设置保存成功后，返回页面可能显示旧缓存；较晚读取可能覆盖正在编辑的值 | 区分当前草稿、已接受结果和后台读取，保持各自的归属 | 保存后的返回状态反映已确认值；读取结果不能擅自覆盖当前修改。此处不改变订阅域名激活合同 |
| 收件箱只用圆点颜色表达已读，窄屏日期列挤压正文 | 显示“已读／未读”；窄屏将完整日期与状态放在正文下方 | 圆点仅作装饰。未读确认仍以服务器响应为准；确认失败时保留未读状态和消息正文 |
| 默认倍率规则被显示成近乎不可读的占位文字 | 仅对这条有扣量后果的信息使用现有可读次要文本样式 | 保留“未设置倍率版本的线路按 1× 扣量”的含义，不改倍率、账本或全局禁用样式 |
| 公告和发送记录的窄表格可横向滚动，但缺少提示 | 复用既有表格容器的横向滚动提示 | 保留全部字段、操作、失败原因和原有表格宽度，不隐藏重要列来消除滚动 |
| 用户列表搜索无匹配时仍显示通用“暂无数据” | 区分无数据与无匹配，提供清除搜索动作 | 加载、读取失败、真实空列表和无匹配各自表达，不把失败写成空数据 |

## 可复用的判断方式

**先保护任务，再调整呈现。** 草稿归属、等待中的决定和旧请求回调应一起检查；只阻止关闭按钮不足以证明页面切换后仍安全。成功、失败、取消、重开和较晚完成分别需要可观察的结果。

**必要信息不依赖颜色或低对比度。** 已读状态需要文本；影响扣量的规则仍是正常信息。局部文字可以使用既有次要层级，不应借机改写全部禁用或占位样式。

**窄屏优先重排，不删事实。** 日期可以移到正文下方；宽表可以提供可发现的滚动入口。没有页面溢出，只说明容器边界受控，并不证明用户能发现被移到视口外的动作。

**无匹配要给恢复路径。** 搜索词没有结果和从未创建数据是不同任务状态；清除搜索比重新说明整项功能更直接。

这些决定延续[项目内容设计规则](CONTENT-DESIGN-RULES.md)与[既有界面审查方法](REFACTORING-UI-AUDIT-2026-10-20.md)。本轮没有新增外部设计来源；既有[来源分层](UX-GUIDELINE-SOURCES.md)及适用边界不变。

## 范围边界

本轮不新增领域能力、基础／专业双轨界面、接口或依赖，不改变授权、模板版本／引用、通知投递、倍率计算或订阅发布合同。源码检查、受控 API 下的真实浏览器呈现、DOM 行为检查和真实后端接受分别记录。全面辅助技术、真实用户理解研究、原生运行时与真实代理流量不由这些界面修复推定。

新增发现仅在确认是本轮回归或严重阻塞时进入本轮，避免把有限修复扩展成无边界重设计。最终结果、保留限制和后续验收均以验证记录为准。
