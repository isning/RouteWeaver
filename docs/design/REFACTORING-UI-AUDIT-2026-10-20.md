## 本轮顺序

先检查层级和信息分组，再核对字阶、色彩、深度、图标与收尾。桌面和窄屏分别记录真实 CSS 视口宽度；1280 / 375 的检查尚未完成，不以现有约 1188 px 截图冒充。修复采用小范围可审查差异，每项记录回归与实际页面证据。未发现问题的控件不为套用规则而重写。

## 已实施的可读性修正

主题从 main.tsx 提取到 theme.ts，保持原有品牌/组件配置。仅在 Tag 组件层调整 warning、success、error、processing 及当前使用的 green/orange 预设；不改变全局告警图标或危险操作的颜色。使用 Ant Design 现有更深色阶；processing 保留品牌文字色、使用浅色背景。

标题区去除操作页面的装饰英文眉题，保留中文任务名称、说明、返回和主要操作；登录页品牌叙述不受影响。静态 surface 保留底色与边框，去除额外阴影，浮层仍沿用组件库层级。完整 Web 回归进行中，完成后复核实际页面。
