# 选择 检查与完成的内容层级审查

2026-10-22。记录 CH-01–04 的发现、修订和有界验收，供后续页面复用。**修订已集成：完整 Web 61 文件 643 测试、最终独立浏览器运行 9 文件 41 项及离线预览检查通过。** 下文保留各自版本与范围；这不是所有 gate 通过、完整无障碍合规或线上部署声明。沿用[内容设计规则](CONTENT-DESIGN-RULES.md)和[UX 方法](UX-METHODOLOGY.md)，不另立一套 guideline。

本轮依据既有业务截图及对应源码作专家审查。截图观察、源码判断、候选回归与最终验收分开；未开展真人无提示任务研究，不能据此声称理解速度提高或达到 Google 产品水准。严重性为项目判断，不是 WCAG 等级。

## 发现与修订方向

| ID | 已观察问题 | 优先级 | 修订方向 |
|---|---|---|---|
| CH-01 | 缺失连接的状态被长内部 ID 挤掉 | P1 | 状态先可读，稳定身份按需可查 |
| CH-02 | 来源导入的披露与完成动作缺少稳定布局归属 | P2 | 同一完成区呈现披露与提交，适应短视口 |
| CH-03 | 新订阅重复模式限制，必经检查的动作名不明确 | P2 | 每个决定上下文表达一次后果，主动作对应真实阶段 |
| CH-04 | 零来源集合仍说明合并及节点保留 | P2 | 只显示当前适用事实，保留全部处理能力 |

### CH-01 状态与身份分别呈现

**观察。** 默认去向和 320 px 策略组修复截图中，长引用 ID 占据选中标签，“当前不可用”被截断。修复入口能聚焦正确控件，并不等于控件里的问题可读。

**决定。** 已确认缺失时用“连接不可用／策略组不可用”；有可靠名称则用“不可用 · 名称”。核对中、等待核对、暂无法核对分别表达，不因读取失败断言对象已删除。稳定 ID 和原选择不变，完整身份放在具名“引用详情”，与默认去向、具体规则或组成员位置关联；多个缺失对象仍可区分，不能只依赖 tooltip。

**验收目标。** 默认去向、第二条规则、多个组成员分别检查；桌面、390／320 px 状态可读，键盘可打开详情并取得完整身份。没有明确选择前不删除引用、不改成直连、不改其他成员。关联 UX-03/08/10/12；GS-18/20/23。

**补测发现。** 为显示长身份而关闭下拉虚拟化的初稿，在 2,000 节点数据下打开即渲染 2,003 项。公共 DOM 回归先失败后通过，修订恢复默认虚拟化，同时保留长 ID 可读性。这是候选引入的性能退化，说明可读性改善不能以全量渲染替代布局修复。移动“引用详情”恢复原生展开标记，并达到项目的 44 px 目标。

读取暂停时，还纠正了缓存状态被误判为“缺失”的分支；这项证据来自独立 Profile DOM 场景，**不证明完整应用离线时仍显示工作区**。状态文案必须服从读取状态和权威数据，不能只凭缓存中没有对象断言已删除。

### CH-02 披露与完成动作属于同一个决定

**观察。** 来源文件弹窗的 1280×900 截图首屏没有提交动作；其他隐私截图在脚本先滚动到按钮后才显示完成区。这证明布局值得修订，不证明整个任务无法完成。

**决定。** 标题、可滚动表单、完成区各有位置；已有隐私说明与取消／提交在同一完成区，不复制两份，也不只固定按钮而让披露滚走。保留四个事实：**平台服务器解析、运营者可处理连接信息、仅本账号可见、不会自动加入共享服务器线路。** 文件控件旁保留“文件先在本地读取，提交后才上传”的时机说明。“启用来源”直接可见，可选导入格式仍可展开；必填项和错误不能被隐藏。

**候选中捕获的回归。** 移动完成区时，候选曾丢失原生提交按钮与表单的关联；重新关联后，又用同一记录同时打开两个实例，发现第二实例的提交和标签可能关联第一实例。公共 DOM 回归先失败后通过，表单、标签及提交改用 React `useId` 提供的实例唯一身份，业务记录身份与提交字段不变。两项问题来自本轮布局候选，不是原基线缺陷。可复用原则是：视觉位置改变须保留原生表单语义，**界面实例身份不等于业务记录身份**。

**验收目标。** 文本／文件／URL，初次打开／文件选择后／选项展开／长错误分别检查。短视口或 200% 文字下允许整个任务区顺序滚动；要求决定点的披露与提交一起可见、焦点不被遮住，不强求所有尺寸永久固定 footer。失败和取消继续遵守输入保留合同。关联 UX-03/10/11/12；GS-07/08/12/17。

### CH-03 下一步是检查还是发布

**观察。** 新订阅弹窗在模式字段和待发布摘要重复纯节点限制；必经检查称为“预览此输出”，与入口“检查发布”及禁用的最终按钮并列。重复是截图观察；可能弱化下一步是设计判断，不是用户实验结果。

**决定。** 模式字段各表达一次选择依据：纯节点不包含策略组、分流规则或运行设置；完整配置包含这些内容及连接。新订阅上下文不再重复通用模式说明，但没有模式字段的独立查看场景仍保留必要解释。检查结果、真实诊断和技术配置入口保留。

主动作在未检查或选项改变后为“检查发布内容”；有效检查后为“创建并发布「订阅名称」”，可另有“重新检查”。检查只生成审阅，不创建订阅。最终确认区保留一次“新建独立链接，其他订阅不变”，对应具体名称、客户端和输出内容；不删重要范围后果，也不把检查通过写成客户端已加载。

**候选中捕获的回归。** 初版将检查按钮原位替换为发布按钮后，双击的后续点击或持续按住 Enter 可越过独立发布决定；这是**本轮候选引入并由失败回归证明的问题，不是对原基线产品的缺陷断言**。修订以独立按钮身份、拒绝多击续事件和检查结果焦点保护新决定，未采用人为延时；对应双击／持续 Enter 回归已由失败转通过。最终浏览器还在原检查坐标确实落到新发布按钮的短视口中验证续点击仍不发布，只有后来明确的新动作才创建一个订阅，其他订阅不变。可复用教训是：按钮变成新动作不代表用户已作出新决定，旧手势不能被新阶段消费。

**验收目标。** 完整／纯节点，未检查／通过／失败／改选项／恢复均覆盖；检查请求与创建发布请求分别断言。双击、按住 Enter、快速完成检查后不得自动发布；释放原手势、重新有意激活后仍可正常发布。旧检查失效、目标身份、未选订阅和显式确认合同不变。关联 UX-01/04/07/10/11；GS-16/18/23；新手势要求是本项目由候选回归形成的方法。

**最终内容复核。** 独立评审复核了本次最终运行的业务截图，其中完整配置 1280／390／320 px、纯节点 320 px 的自然检查结果焦点状态保留对象、客户端、模式和独立链接后果。必要信息已有明确位置，不再往完成区增加重复小字；窄屏的可选技术详情仍可滚动查看。这是选定状态的专家像素复核，不扩称所有状态或真人理解通过。

### CH-04 省略无关叙述而不隐藏能力

**观察。** 390 px 集合编辑器截图的确认框背景中，“暂无可选来源”下仍显示合并箭头和“按来源顺序保留所有节点。添加步骤，开始整理”。集合列表本身的空态已简洁，不在本次问题范围。

**决定。** 来源字段明确为“订阅来源”；至少两个选中来源才呈现顺序合并提示及排序控件。零来源时区分“暂无可选来源”和“尚未选择来源”，不宣称已保留节点，不新增教学段落。处理控件仍可用，允许先准备步骤。有来源而该层没有步骤时可用“未添加处理步骤”；“添加处理步骤”控件已表达动作，不再重复教学句。

**验收目标。** 零／一／多来源、有／无步骤分别检查，关闭确认框后直接审查编辑器。逐来源处理、合并后处理、排序、预览与保存均保留；条件显示不改变步骤或顺序，也不假称前一层过滤过的节点仍全部保留。关联 UX-03/04/08；GS-10/16/17/23。

**补测发现。** 移动保存按钮实测由 88×38 px 修订为 88×44 px；这是项目目标，不是 WCAG AA 的统一 44 px 要求。公共处理步骤组件的默认空态随后也改为中性表达，追加 32 项工作区 DOM 回归和类型检查通过。现有生产调用处已显式传入对应文字或不显示说明；此前 8 项浏览器任务未因这次默认值清理重跑，不能当作后续版本的新浏览器结果。

## 下一轮待处理的两个任务问题

后续只读源码与截图专家审查还发现以下两项；**它们不属于本轮 CH-01–04 已修范围**，也不是用户实验结论。

- **集合编辑器缺少任务内添加／导入来源入口。** 目前仍可保存或明确放弃后离开，到订阅来源添加，再重开集合；这是任务连续性问题，不是无法完成的死路。下一轮应检查怎样在保留集合草稿和明确保存边界的前提下，就地补充来源。
- **折叠来源行的处理信息不足。** 收起时只有名称／序号，来源处理的用途及已有步骤状态须展开才能看见。下一轮应让用户在收起时仍能判断该来源是否有处理步骤，同时保留展开后的完整编辑能力。

后续范围限定为这两个任务问题，不开展全局术语替换。本轮有界验收完成不等于整体产品体验已全部验收。
