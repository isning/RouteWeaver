# 恢复流程与界面一致性检查清单

2026-10-22。适用于 RouteWeaver 的错误修复、认证恢复、迟到结果、返回导航和移动确认。**检查项不是通过记录**；本轮状态见[发现与证据登记](RECOVERY-UX-EVIDENCE-2026-10-22.md)。

## 来源和方法分开

- **已有来源指导**：沿用仓库[GS 来源目录](UX-GUIDELINE-SOURCES.md)的作者、URL、版本、访问日期和适用边界。本次读取的是登记文档，没有重新浏览或新增外部指南；不把历史核验写成本次访问。
- **项目综合规则**：遵守 [AGENTS](../../AGENTS.md)、[内容设计规则](CONTENT-DESIGN-RULES.md)、[UX 方法](UX-METHODOLOGY.md)及[成熟度审查](PRODUCT-MATURITY-REVIEW-2026-10-22.md)。统一界面、结果归属和下面的验证步骤是项目决定，不归称 Google 或 IBM 的原始规则。
- **本轮实测发现**：问题、测试层次、冻结版本和未决项单独记录。内部评审、DOM、浏览器、像素观察、真人理解研究和部署证据不可相互替代；本轮不声称 Google 认证、完整 WCAG 合规或真人研究结论。

## 每次修改前

- [ ] 写出一个具体任务、对象、用户决定和结果；确定当前值属于账户、会话、视图、草稿还是某次请求。
- [ ] 为每段可见文字标记对象／动作／选择／输入／状态／后果／恢复职责。先改标签与交互，再决定是否需要辅助说明；不以新口号替代旧口号。
- [ ] 同一事实在最有用处表达一次。保留决定点的隐私、破坏后果、未知状态、身份和发布范围；不能一律折叠或塞入 tooltip。
- [ ] 固定源码清单、运行配置、数据和证据输出策略。记录测试开始与结束的清单；中途源码变化只能作为诊断，不能签收该组合版本。

## 错误直接指向发生位置

- [ ] 以“稳定对象身份＋具体字段／规则／组位置”识别错误，不仅用错误文本或引用 ID 去重。同一引用出现在两条规则和一个组，仍有三个独立修复位置。
- [ ] 后端结构化位置须与当前草稿核对；重排、删除、改稿后不得沿旧索引修错对象。仅同一控件上的重复提示可合并。
- [ ] 修复入口打开并聚焦准确控件，保留用户输入和指定发布目标；不自动替换缺失连接、不自动保存或发布。
- [ ] 修改后旧检查结果失效，重新检查通过且用户明确确认后才执行。验证未选兄弟对象保持不变。

## 账户 会话与迟到结果

- [ ] 账户／角色拥有私有草稿和缓存；会话代次拥有短期授权、CSRF 和响应有效性。相同账户更新会话不应无故丢稿；不同账户／角色不得继承旧草稿。
- [ ] 区分 routine checking 的只读保留与实际过期／离线／身份变化的隐藏恢复；检查门户弹层，不能只隐藏页面主体。
- [ ] 晚到登录或邀请 response body 不能覆盖当前 cookie 身份；成功回调触发权威身份核对。旧表单失败不得清除后续尝试取得的 token。
- [ ] 文件准备、请求发出、服务端提交、响应读取和 UI 完成回调分别定义归属；异步准备后、实际发出前再核对权限。
- [ ] **服务端成功事实不等于当前 UI 有权接受完成回调。** 旧保存即使已提交，也不得关闭新草稿、改变新视图或清除新任务的 dirty 状态；不能伪称撤销服务端写入。
- [ ] 覆盖旧成功／旧失败、切换账户／角色／视图、改稿、卸载、重开及暂停后恢复。不得自动重放写操作；结果不明时给核对路径，而非编造失败或成功。

## 真实输入 焦点与渲染

- [ ] 点击**可见 label**，检查 `label.control` 指向可见输入，再用键盘输入。`locator.fill` 能填入目标不证明原生标签关联正确；共存和 force-rendered 表单一起测。
- [ ] 检查 HTML `hidden` 的实际 computed style 和像素结果。组件 CSS 可能覆盖它；属性存在不证明原生文件输入真的不可见。再验证本地选择器仍工作、同名文件改内容可重读。
- [ ] 焦点恢复既检查 active element，也检查完整边界在视口内及可见焦点样式。语义聚焦通过不代表焦点环可见。
- [ ] 使用真实浏览器窗口操作验证 trusted focus／visibility 及实际身份请求。Playwright 默认聚焦模拟、`bringToFront` 或合成 focus 事件不得冒充 OS／浏览器原生证据；浏览器文件 chooser 自动化不等于桌面 OS picker 易用性研究。
- [ ] 320／390 像素宽度测量实际点击框、左右位置、换行、computed margin 和整页宽度。44 px 是本项目既有触摸目标，不误写成 WCAG 2.2 AA 的普遍44 px要求。
- [ ] 弹层动画自然结束且对话框可见后截图；检查最终像素。未呈现对话框的图片不得用于验收；不在缺乏直接证据时断言其成因。

## 返回与历史

- [ ] 原生 Back／Forward、详情关闭、深链和页面内跳转分别验；明确目标优先于记忆筛选，不能被无匹配列表隐藏。
- [ ] 列表上下文仅保留必要的账户内存状态；搜索、草稿、凭据和访问地址不写 URL／history／storage。元数据只能含明确允许的非私密证明。
- [ ] 滚轮后等待 compositor 渲染稳定再记录离开位置；验证返回位置和原触发器，不以人为延时绕过真实问题。
- [ ] dirty 导航先恢复当前有效入口再询问；取消保稿、放弃只执行一次。认证暂停不得偷偷接受导航或留下隐藏确认。
- [ ] truly unknown history 无可靠方向时不猜测：若继续编辑需建立新记录并清除 Forward，必须在决定点披露，不能称完全无损历史。

## 阶段交付门槛

- [ ] 将产品问题、测试契约过时、自动化缺陷、资源／环境阻塞分开。遵守生产限流，修测试 setup 而非放宽或绕过限流。
- [ ] 测试断言全过但 runner exit 1／unhandled error 仍是失败。修 cleanup 后需整套干净退出；单文件复测不能替代全套复验。
- [ ] 原失败未定位，即使再次通过也保留“未解释／未证明修复”。候选已绿、已合入、当前整体验收是三个不同状态。
- [ ] 禁用可能收集凭据的 trace、视频、自动失败截图与自动页面快照；必要诊断只记状态，不记 cookie/token/请求体。仅手动截取非敏感合成业务状态，逐图检查后供阶段完成汇报。
- [ ] 保留代码、候选差异、来源和证据路径；交付明确当前边界与待确认项，不把测试数量当成内容质量或满意度评分。
