## Acceptance criteria

- [ ] Complete backups contain recovery-required secrets only in authenticated encryption; template sharing remains redacted and ordinary subscriptions retain only needed connection credentials.
- [ ] Wrong key, truncated data, tampered ciphertext and unsupported schema are rejected before mutation.
- [ ] Restore preserves users, grants, profile revisions, publication links and ledger history; conflict and target overwrite behavior are explicit.
- [ ] Migration/restore fault injection proves a recoverable prior state and reports verified completion; no automatic third-party upload or secret sharing occurs.
